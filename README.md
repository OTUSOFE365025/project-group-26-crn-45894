# SOFE 3650 – AIDAP Project  
## Phase 2 – ADD Iteration 1 & Iteration 2

This folder contains all deliverables for **Phase 2** of the AIDAP architecture project.  
All documents follow the structure and style of the **ADD FCAPS Case Example**, including  
logical views, deployment views, scenarios, and refinement steps.

---

## Contents

### **1. Iteration1.md**  
Implements **ADD Iteration 1**, covering:
- Selected design drivers  
- Primary use cases  
- Quality attributes with priority levels  
- System constraints & architectural concerns  
- Reference architecture selection  
- High-level module structure (FCAPS-style)  
- Logical View – Iteration 1  
- Deployment View – Iteration 1  
- Analysis of current design

### **2. Iteration2.md**  
Implements **ADD Iteration 2**, covering:
- Refinement of architectural elements  
- Domain model  
- Module decomposition and service responsibilities  
- Detailed service interfaces  
- Sequence diagrams (UC-1 and UC-2)  
- Logical View – Iteration 2 (same structure as Iteration 1, AIDAP-specific names)  
- Deployment View – Iteration 2  
- Driver coverage and work allocation

# AIDAP — AI‑Powered Digital Assistant Platform (SOFE3650 Project)
Project overview
- AIDAP provides conversational access to institutional data (schedules, announcements, analytics) for Students, Lecturers, Administrators.

Repository contents (Deliverable 1)
- `Use Cases.md` — defined actors, primary use cases, flows, extensions and traceability.
- `Quality Attributes.md` — prioritized quality attributes, measurable scenarios, and tactics.
- `Constraints.md` — system and implementation constraints to be respected.
- `Concerns.md` — architectural concerns and trade-offs for design decisions.
- `ADD Iteration 1/2/3` — ADD artifacts and design iterations (no changes required for Deliverable 1).

Business Case (brief)
- Problem: Fragmented access to academic and institutional data reduces efficiency and engagement.
- Solution: Central conversational platform integrating LMS, registration, calendar, and email with personalization and analytics.
- Benefits:
	- Improved student awareness and engagement.
	- Reduced administrative support overhead.
	- Centralized analytics for instructors and administrators.
- Risks: Data privacy/compliance, integration complexity, model latency vs cost.
- Timeline (high-level): Deliverable 1 (Requirements) — Oct 28; ADD Iterations 1 & 2 — Nov 16; Final design & implementation — Dec 6.

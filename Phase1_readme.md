# AIDAP – AI-Powered Digital Assistant Platform

## Overview

The **AI-Powered Digital Assistant Platform (AIDAP)** is a university-focused conversational AI system designed to provide students, lecturers, and administrators with instant access to institutional information such as course schedules, announcements, deadlines, and analytics. The platform integrates with existing university systems (LMS, registration, calendars, and email) and leverages AI models to interpret natural language queries and provide contextual answers.

3. **Deliverable 3 – Design of a Use Case (Due Dec. 6, 2025)**
   Implements a selected use case, linking architectural components to source code and conducting an ATAM-style evaluation.
